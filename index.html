VolleyBot Backups

VolleyBot Backups est un outil privé utilisé pour sauvegarder les données du bot Discord de l'association de volleyball ESGI.

Les sauvegardes sont chiffrées localement avant leur envoi vers Google Drive.

L'application utilise uniquement l'autorisation Google Drive nécessaire pour gérer les fichiers qu'elle crée elle-même.
